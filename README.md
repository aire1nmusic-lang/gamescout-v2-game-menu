# GameScout — Вариант 2 · Игровое меню

Экран выбора сервера внутри самой игры: золотые рамки L2, пиксельное меню Minecraft, телефон и неон GTA.

**Открыть:** https://aire1nmusic-lang.github.io/gamescout-v2-game-menu/

Один из трёх вариантов дизайна страницы мира GameScout (Lineage 2, Minecraft, GTA RP) для выбора стиля.
Внизу экрана панель: «Как сейчас» показывает живой сайт gamescout.online (снимок), «Новый вид» — этот вариант; там же переключаются миры.

- Данные: снимок публичного каталога gamescout.online (src/data/catalog.json), ничего не выдумано.
- Арт и персонажи: из проекта GameScout (public/media).
- Вход, голосование и GS Coins работают только на основном сайте; кнопки ведут туда.

Запуск: `npm ci && npm run dev`, сборка: `npm run build`.
